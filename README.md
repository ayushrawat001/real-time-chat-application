# Real-Time Chat Application

A real-time chat application built using React, Node.js,
Express.js, MongoDB and Socket.IO.

## Features

- User authentication
- Real-time messaging
- User conversations
- Online/offline status
- Responsive interface

## Tech Stack

Frontend:
- React
- Redux
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Socket.IO
